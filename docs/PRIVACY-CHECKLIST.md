# Pre-publication review checklist

Run before every commit, issue, pull request, or README edit.

- [ ] No unpatched or non-public vulnerability details involving any third party
- [ ] No actual user data, passwords, authentication cookies, JWTs, API tokens or private keys
- [ ] No raw HAR, PCAP, screenshots or private Bugcrowd report references
- [ ] No live NASA hostnames added to public examples without a compelling and permission-safe reason
- [ ] No false claims of report acceptance, bounty, Hall of Fame or NASA LOR
- [ ] All testing described was authorized, and examples only use synthetic data
- [ ] Any research publication follows the NASA/Bugcrowd disclosure policy and explicit coordination
