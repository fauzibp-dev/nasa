# NASA Letter of Recognition (LOR): eligibility and truthful portfolio

Official policy: https://www.nasa.gov/vulnerability-disclosure-policy/ (version 1.6.2 — April 30, 2026). Recheck current policy for changes.

NASA says:
- Not every report qualifies.
- Duplicates and previously known issues are ineligible.
- Only **P1–P4** reports that were **validated, accepted, and confirmed fixed** qualify.
- Its VDP is not a cash bug-bounty program.

A submitted report is not the same as an accepted vulnerability. A validated report is not the same as an LOR received. The final decision belongs to NASA/Bugcrowd.

## Private evidence checklist (do not commit sensitive copies)

- Exact Bugcrowd submission reference, in a PRIVATE record
- NASA/Bugcrowd status messages validating and accepting report
- Confirmation of completed fix and any delivered LOR
- Any explicit permission needed to publish the report or report-specific details
- A redacted acknowledgement image only if authorized

## Public portfolio example — only AFTER real recognition

> Independently recognized by NASA for a responsibly disclosed and remediated vulnerability (NASA Letter of Recognition, [month year]).

Do not use this wording unless NASA actually issued an LOR. An offline training exercise is *not* a NASA discovery.

## Alternative achievements while learning

Document completed PortSwigger Web Security Academy labs or earn an independently assessed credential. Never mislabel a course completion, lab simulation, or third-party certificate as a NASA award.
