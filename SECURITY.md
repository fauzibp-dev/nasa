# Security & responsible disclosure

**This public repository is not an official NASA reporting channel.** Never create a public issue or commit containing a suspected unpatched NASA vulnerability, private Bugcrowd report, access token, personal information, private system data, or exploit evidence.

If you find a real NASA vulnerability, stop testing once confirmed and report it privately through the official [NASA Bugcrowd VDP](https://bugcrowd.com/engagements/nasa-vdp), following the live scope and policy. NASA's [VDP](https://www.nasa.gov/vulnerability-disclosure-policy/) requests confidentiality while remediation is underway.

For a vulnerability in the *example code in this repository*, do not paste secrets or sensitive evidence. If you need to report a flaw here privately, use GitHub's private vulnerability reporting feature if enabled by the repo owner; otherwise contact the repository owner privately via an established trusted channel.

All tools in this workspace are offline-first. Their existence never constitutes authorization for third-party testing.
